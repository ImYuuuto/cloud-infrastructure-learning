# Nano 

nano is a terminal text editor.

open file with it "nano notes.txt"
with it u can write and edit content as it has shortcuts:
Ctrl + O : "Save",
enter : "Confirm file name",
Ctrl + X : "Exit",
Ctrl + K : "Cut current line",
Ctrl + U : "Paste cut text",
Ctrl + W : "Search",
Ctrl + G : "Help",
