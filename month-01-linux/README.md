# Month 01 — Linux & Bash

This month builds practical Linux administration skills, from navigating the filesystem to writing Bash scripts and automating routine tasks.

## Learning plan

### Week 1 — Linux fundamentals

- Linux architecture
- Filesystem hierarchy
- Navigation and file management
- Reading and editing files
- Permissions
- Users and groups

### Week 2 — System administration

- Processes (`ps`, `top`, `htop`, `kill`)
- Package management (`apt`)
- Environment variables
- `PATH` and executable permissions

### Week 3 — Networking and services

- Networking fundamentals
- IP addresses and ports
- DNS and troubleshooting
- SSH and remote connections
- Services and systemd
- Logs and journalctl
- Firewall basics

### Week 4 — Bash scripting and automation

- Variables and input
- Conditions
- Loops
- Functions
- Arguments
- Exit codes
- Pipes and redirection
- Cron jobs and automation
