# Cloud Infrastructure Learning

A six-month practical learning journey focused on Linux, networking, Docker, cloud computing, CI/CD, Infrastructure as Code, and Kubernetes.

## Goals

Build a solid foundation in cloud infrastructure and platform engineering through practical projects and hands-on labs.

## Projects

Each month includes practical labs, notes, and a project demonstrating the skills learned.

## Philosophy

Learn by building, experiment, break things, troubleshoot, document, and understand the systems behind the tools.
