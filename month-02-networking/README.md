**Practical work:**
- Troubleshoot broken network connectivity.
- Diagnose DNS resolution failures.
- Identify unreachable hosts and closed ports.
- Trace network paths using `traceroute` or `tracepath`.
- Capture traffic using `tcpdump`.
- Analyze packet captures using Wireshark.
- Configure firewall rules using UFW.
- Test allowed and blocked connections.

**How to know I'm good:**
- Follow a systematic troubleshooting process.
- Identify whether a problem comes from DNS, routing, connectivity, or ports.
- Use Linux networking tools independently.
- Read basic packet captures.
- Configure and verify basic firewall rules.
